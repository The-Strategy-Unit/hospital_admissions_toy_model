# Repository for code related to the "Do we need more beds?" tool
This repository supports the code used to build the "Do we need more hospital beds?" RShiny App. 

# Do we need more hospital beds? 
This interactive tool helps you explore the relationship between admissions growth, length of stay, bed occupancy rate and number of hospital beds.

See our blog for a longer narrative on the tool and why we built it: https://www.strategyunitwm.nhs.uk/news/hidden-challenge-heart-10-year-plan.

# This is a national focused tool - could it be used more locally?
Yes - the tool could support more local modelling by providing local data on historical admissions, occupancy, LoS and numbers of hospital beds. This would require supplying a "Collating the Data.csv" file including that information. However this tool is intended as an intuition/exploratory model and not a forecast so we recommend that all assumptions and limitations (as listed in the Methodology section of the app) are considered before taking this further. 

For more information on the tool feel free to reach out to us at strategy.unit@nhs.net.
